# Awase-synthetics

A Deriv synthetic indices pairs signal generation website.

## Features
- Express.js backend with WebSocket support for real-time signals
- React frontend with TailwindCSS for modern UI
- Real-time signal generation (5-30 signals daily)
- Dashboard for tracking signal accuracy and performance
- API integration with Deriv
- Database setup with PostgreSQL
- Signal generation algorithms based on technical analysis

## Getting Started

### Prerequisites
- Node.js
- Docker

### Installation

1. Clone the repository
2. Run `npm install` in both the `client` and `server` directories
3. Start the application using Docker or npm scripts.
